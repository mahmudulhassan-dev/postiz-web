Native AmanaFlow MCP Server Configuration

Connect AI tools to your AmanaFlow instance

AmanaFlow exposes a native Model Context Protocol (MCP) endpoint that enables AI tools to list connected channels, draft multi-platform posts, upload media assets, and trigger scheduled campaigns without human browser interaction.

// Add to your Claude Desktop or Cursor mcp_config.json:
{
  "mcpServers": {
    "postiz": {
      "url": "https://post.amanaflow.com/api/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_AMANAFLOW_API_KEY"
      }
    }
  }
}
